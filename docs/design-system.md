# Daymark design system

The implementation reference is a calm, open task list: a true-white content canvas, a cool-gray sidebar, graphite text, cobalt actions, lavender morning accents, and amber evening accents.

- Canvas: `#ffffff`; navigation rail: `#f5f7fa`; primary text: `#151922`; muted text: `#70798a`.
- Accent: `#1768e5`; morning: `#7954d6`; evening: `#f59b23`; success: `#45bd62`.
- Typography: system sans, 14px UI chrome, 16px task rows, 42px desktop page title, 34px mobile page title.
- Geometry: open rows with 1px dividers, 20–28px section rhythm, circular check controls, 12px selected-navigation radius, one elevated circular add action.
- Icons: Lucide outline family at 1.8px stroke, 18–22px in navigation, 16px for metadata.
- Motion: 180ms row and navigation transitions; spring-like quick-add sheet; completion feedback with a brief scale pulse.
